## ✦ Projetos em destaque

### 🛍️ E-commerce de perfumes com assistente de IA

**Código privado** · Chamada de funções (*tool calling*) · Consulta ao catálogo

O assistente usa chamadas de função para consultar o catálogo no banco de dados da loja. Na conversa, ele pode:

- Responder a dúvidas sobre a loja e listar os perfumes do catálogo.
- Recomendar perfumes com base nas preferências do cliente.
- Direcionar o cliente à página do produto escolhido.
